# 🧠 LeetCode Solutions

A clean, organized collection of coding-problem solutions grouped by topic. 📚💻

## 📂 Repository Structure

Solutions are organized by the main data structure or algorithmic technique used:

- 🧮 `arrays/` — Array and two-pointer problems
- 🔤 `strings/` — String manipulation and pattern problems
- 🔗 `linked-list/` — Linked-list problems
- 🌳 `trees/` — Binary trees and tree traversals
- 🌲 `binary-search-tree/` — BST-specific problems
- 🕸️ `graphs/` — Graph traversal and graph algorithms
- 📚 `stack/` — Stack-based problems
- 🚶 `queue/` — Queue and deque problems
- ⛰️ `heap/` — Heap and priority-queue problems
- 🔎 `binary-search/` — Binary-search techniques
- 🧮 `hashing/` — Hash maps and hash sets
- 🧩 `dynamic-programming/` — Dynamic programming
- 💡 `greedy/` — Greedy algorithms
- 🔄 `recursion/` — Recursive solutions
- 🧭 `backtracking/` — Backtracking and search
- 🌐 `trie/` — Trie and prefix-tree problems
- ⚙️ `sorting/` — Sorting-based solutions
- 🔢 `math/` — Mathematical and number-theory problems
- 🧠 `bit-manipulation/` — Bitwise techniques
- 📐 `matrix/` — 2D arrays and matrix problems
- 🧰 `design/` — Data-structure design problems

## ✨ Organization Principles

- 📁 Every solution belongs to the most relevant topic folder.
- 🏷️ File names use the problem number and a readable problem name when available.
- 💬 Solutions stay clear and easy to review.
- ⏱️ Time and space complexity can be documented where useful.
- 🔄 Problems involving multiple techniques are placed under the technique that best represents the solution.

## 🚀 Purpose

This repository is a personal reference for practicing **data structures, algorithms, problem solving, and clean implementation**.

Happy coding! 💻🔥
